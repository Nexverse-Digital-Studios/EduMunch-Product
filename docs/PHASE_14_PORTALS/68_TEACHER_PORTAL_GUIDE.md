# 68 - Teacher Portal Guide

## Overview

The Teacher Portal is a comprehensive platform for managing classes, tracking student progress, delivering content, assessing learning, and communicating with students and parents. This guide explains all features available to teachers.

**Target Audience:** Faculty members and instructors

**Access:** Teachers log in with credentials at `teacher.edumunch.com`

## 1. Getting Started

### Logging In

1. Navigate to teacher portal login page
2. Enter **Email** or **Employee ID**
3. Enter **Password**
4. Complete multi-factor authentication if enabled
5. Click **Login**

### Initial Setup

Complete setup for smooth experience:
1. Update profile with photo and bio
2. Add office hours and availability
3. Configure communication preferences
4. Create presentation templates
5. Upload initial resources

### Role & Permissions

Your access depends on role:
- **Faculty**: Teach assigned courses
- **Department Head**: Manage department courses
- **Coordinator**: Oversee program curriculum
- **Admin**: Full system access

Ask admin to verify your role setup.

3. Add details:

   - Instructions

4. Add rubric (optional)
5. Attach resources
6. Configure options:

   - Peer review?
   - Late submission?
7. Publish

**Assignment Types:**
- **Text Assignment**: Students type response
- **File Upload**: Submit files
- **Quiz**: Automated questions
- **Project**: Group submission
- **Practical**: Code/design submission

### Assignment Rubrics

**Creating Rubric:**

4. Set scoring levels:

**Rubric Benefits:**

- Consistent evaluation

- Reduced grading time

## 12. Troubleshooting

### Common Issues

**Can't Upload Video**

*Problem:* Video file rejected

Solutions:
1. Check file format (MP4, MOV)
2. Verify file size (max 500MB)
3. Reduce video resolution
4. Try uploading smaller segment
5. Use different file format
6. Contact admin if issue persists

**Students Can't See Content**

*Problem:* Students report missing materials

Solutions:
1. Verify content is published
2. Check access dates (may be hidden)
3. Check file format compatibility
4. Test with different browser
5. Check student enrollment status
6. Clear student's browser cache

**Attendance Not Saving**

*Problem:* Attendance marks lost

Solutions:
1. Check internet connection
2. Use supported browser
3. Close attendance window properly
4. Wait before closing page
5. Try marking fewer students at once
6. Save periodically (don't mark all at once)

**Grade Calculation Wrong**

*Problem:* Final grade doesn't match calculation

Solutions:
1. Verify weightage setup
2. Check for missing assignment grades
3. Confirm extra credit applied correctly
4. Check for grade curves applied
5. Verify grading scale
6. Contact admin for data audit

**Can't View Student Work**

*Problem:* Cannot open student submissions

Solutions:
1. Check file format compatibility
2. Ensure you have viewing permissions
3. Try different browser
4. Download file to open locally
5. Request student resubmit
6. Contact admin

### Performance Issues

**Slow Loading**

Solutions:
1. Check internet speed
2. Close unnecessary tabs/programs
3. Clear browser cache
4. Disable browser extensions
5. Use wired connection
6. Upgrade browser to latest version

**Frequent Logouts**

Solutions:
1. Check password expiry settings
2. Increase session timeout
3. Disable device fingerprinting (in security)
4. Clear cookies
5. Update browser
6. Use newer device/browser
