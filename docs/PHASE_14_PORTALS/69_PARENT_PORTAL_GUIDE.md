# 69 - Parent Portal Guide

## Overview

The Parent Portal enables parents to monitor their child's academic progress, track attendance, manage fees, and communicate with teachers and school administration. This guide walks parents through all portal features.

**Target Audience:** Parents and guardians of students

**Access:** Parents log in at `parent.edumunch.com`

## 1. Getting Started

### Account Creation

**Initial Setup:**
1. School provides login credentials
2. Log in to parent portal
3. Complete profile:
   - Full name
   - Contact information
   - Relationship to student
   - Address
4. Set security questions
5. Create password

### First Login

1. Navigate to parent portal login page
2. Enter email address provided by school
3. Enter temporary password
4. Change password to something secure
5. Complete profile setup

### Multi-Child Support

If you have multiple children:
1. Log in once with one credentials
2. Select child to view from dropdown
3. Each child shows separate data
4. Monitor all from one account
5. Switch between children easily

### Security Setup

**Password Best Practices:**
- Use at least 8 characters
- Mix uppercase, lowercase, numbers, symbols
- Don't use child's name or birthdates
- Change every 90 days
- Never share with child

**Account Recovery:**
1. Set security questions
2. Provide backup email
3. Save backup email somewhere safe
4. Use "Forgot Password" if needed

## 4. Academic Progress

### Viewing Grades

**All Grades:**
1. Go to **Grades** or **Marks**
2. View by:
   - All subjects
   - By semester
   - By assignment type
   - Chronological

**Grade Details:**
1. Click grade to see:
   - Assignment/exam name
   - Student answer/submission
   - Teacher's grading
   - Teacher feedback
   - Rubric scores (if applicable)
   - Due date and submission date

### Grade Components

Grades typically include:
- **Assignments**: Regular homework and projects (20%)
- **Tests**: Unit tests and quizzes (30%)
- **Practicals**: Lab work or demonstrations (20%)
- **Participation**: Class involvement (10%)
- **Final Exam**: Semester/annual exam (20%)

**Grade Breakdown:**
1. Go to **Analytics**
2. See subject-wise breakdown
3. View component-wise contribution
4. Understand how final grade is calculated

### Performance Trends

**Viewing Trends:**
1. Go to **Performance Analysis**
2. See charts showing:
   - Grade trend over time
   - Subject-wise comparison
   - Performance vs. class average
   - Semester-wise improvement
   - Areas of strength/weakness

**Interpreting Trends:**
- Improving trend: Student making progress
- Declining trend: May need intervention
- Consistent high: Strong performer
- Consistent low: Needs support
- Variable: Inconsistent performance

### Subject Performance

**Per-Subject Analysis:**
1. Click subject name
2. View:
   - All grades in subject
   - Component-wise breakdown
   - Teacher comments
   - Topics with low scores
   - Recommended actions

### Weak Areas

**Identifying Weak Areas:**
1. Go to **Performance**
2. Look for "At Risk" or "Low Score" flags
3. System identifies:
   - Consistently low grades
   - Missed multiple assignments
   - Low test scores
   - Specific challenging topics

**Getting Help:**
1. Review recommended resources
2. Schedule meeting with teacher
3. Request extra tutoring
4. Check available remedial materials
5. Plan support strategy

## 5. Attendance Tracking

### Current Attendance

**Viewing Attendance:**
1. Go to **Attendance**
2. See overall percentage
3. View by subject (if applicable)
4. Check attendance calendar

**Attendance Information:**
- Total classes held
- Total present
- Total absent
- Leaves approved
- Current percentage
- Minimum required (usually 75%)

### Attendance Calendar

**Calendar View:**
1. Month-by-month calendar
2. Each day shows:
   - P (Present)
   - A (Absent)
   - L (Late)
   - LV (Leave)
3. Click date for details
4. See color-coding

### Attendance Status

**Green**: Good attendance (above 90%)  
**Yellow**: Caution zone (75-90%)  
**Red**: At-risk (below 75%)

**At-Risk Status:**
If attendance falls below 75%:
- School will notify
- May affect academic performance
- May prevent exam appearance
- Immediate action needed

### Managing Attendance Issues

**For Medical Absence:**
1. Provide medical certificate
2. Request sick leave
3. Submit documentation
4. Wait for approval

**For Authorized Absence:**
1. Inform school in advance
2. Submit leave request
3. Provide reason
4. Wait for approval

**For Unexplained Absence:**
1. Contact school immediately
2. Provide explanation
3. Request leave retroactively
4. May be marked as unauthorized

## 10. Troubleshooting

### Common Issues

**Can't Login**

*Problem:* "Invalid credentials" message

Solutions:
1. Verify username/email spelling
2. Check caps lock on keyboard
3. Use "Forgot Password" link
4. Clear browser cache and cookies
5. Try different browser
6. Contact school admin if still stuck

**Can't See Child's Data**

*Problem:* "Child not linked" or empty dashboard

Solutions:
1. Verify child is enrolled
2. Check if enrollment processed
3. Confirm correct school selected
4. Wait 24 hours for system sync
5. Contact school admin

**Missing Grades**

*Problem:* Don't see latest grades

Solutions:
1. Grades might not be published yet
2. Refresh page (Ctrl+F5)
3. Clear browser cache
4. Check if assignment graded
5. Wait 24-48 hours for grade posting
6. Contact teacher if overdue

**Payment Failed**

*Problem:* Payment not processed

Solutions:
1. Check card balance/limit
2. Verify card details
3. Try different payment method
4. Contact bank to verify card
5. Use offline payment option
6. Contact school admin

**Can't Upload Documents**

*Problem:* File upload error

Solutions:
1. Check file size (max usually 10MB)
2. Use supported format (PDF, Image, Word)
3. Scan clearly if image
4. Try different file
5. Use different browser
6. Contact admin if error continues

### Technical Issues

**Slow Loading**

Solutions:
1. Check internet connection
2. Close other browser tabs
3. Clear browser cache
4. Use wired internet if possible
5. Update browser to latest version
6. Try accessing on different device

**Frequent Logouts**

Solutions:
1. Don't leave portal idle too long
2. Disable 2FA temporarily
3. Clear cookies
4. Update browser
5. Try different device
6. Contact admin for session settings
