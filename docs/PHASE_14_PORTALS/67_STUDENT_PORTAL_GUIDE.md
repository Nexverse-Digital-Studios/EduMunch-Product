# 67 - Student Portal Guide

## Overview

The Student Portal is the central hub where students access their courses, submit assignments, view grades, track attendance, participate in learning activities, and communicate with teachers and peers. This guide walks students through all features and how to use them effectively.

**Target Audience:** Students across all academic levels

**Access:** Students log in with their credentials at `student.edumunch.com`

## 1. Getting Started

### Logging In

1. Navigate to the student portal login page
2. Enter your **Registration Email** or **Roll Number**
3. Enter your **Password**
4. If you see "Enter OTP", check your registered email for the one-time password
5. Click **Login**

**First-time Setup:**
- Change your password in Account Settings
- Upload a profile picture
- Verify your contact number
- Set notification preferences

### Password Security

- Passwords must be at least 8 characters
- Include uppercase, lowercase, numbers, and special characters
- Never share your password
- Change password every 90 days
- If forgotten, click "Forgot Password" and follow email instructions

### Two-Factor Authentication

For added security, enable 2FA:
1. Go to **Settings → Security**
2. Click **Enable Two-Factor Authentication**
3. Choose method: Authenticator App, SMS, or Email
4. Follow setup instructions
5. Save backup codes in a secure place

## 3. Courses & Learning

### Browsing Courses

1. Click **Courses** in main menu
2. View all enrolled courses
3. Click any course card to enter

### Inside a Course

**Course Navigation:**
- **Overview**: Course details, syllabus, schedule
- **Content**: Learning materials (videos, PDFs, links)
- **Assignments**: Active and past assignments
- **Tests**: Quizzes and exams
- **Discussion**: Q&A and discussions
- **Resources**: Additional study materials
- **Announcements**: Course updates

### Learning Path

Courses are organized in learning paths with prerequisite requirements:

1. Complete foundational topics first
2. Topics marked with lock icon require prerequisites
3. Each topic shows progress: Not Started → In Progress → Completed
4. Earn badges for completing milestones
5. Progress tracked automatically

### Video Lessons

**Watching Videos:**
1. Click video to play
2. Video quality adjusts automatically
3. Pause to take notes
4. Download optional (if enabled)
5. Subtitles available in Settings

**Video Features:**
- Playback speed (0.5x to 2x)
- Chapter markers
- Transcript search
- Bookmarks
- Notes within video
- Continue where you left off

### Downloads & Offline Access

1. Go to **Settings → Offline Access**
2. Select materials to download
3. Available offline in mobile app
4. Syncs when online again

### Notes & Bookmarks

**Taking Notes:**
1. Click **Take Notes** while viewing content
2. Type or paste notes
3. Notes sync across devices
4. Search all notes from **My Notes**

**Bookmarking:**
1. Click bookmark icon on content
2. Organize with tags
3. Access from **My Bookmarks**

## 4. Assignments

### Viewing Assignments

1. Click **Assignments** in course or dashboard
2. Filter by: All, Due Soon, Submitted, Graded
3. Click assignment to open

### Assignment Details

Each assignment shows:
- **Due Date & Time**: When to submit
- **Submission Status**: Not Submitted, Submitted, Late, Graded
- **Instructions**: What you need to do
- **Rubric**: How you'll be graded (if provided)
- **Attachments**: Resources to help
- **Comments**: Teacher feedback

### Submitting Assignments

**For Text Assignments:**
1. Click **Submit Answer**
2. Type or paste your response
3. Format text (bold, italic, lists, etc.)
4. Add attachments (optional)
5. Click **Submit**

**For File Assignments:**
1. Click **Upload File**
2. Select file from computer
3. File size limit: 25MB
4. Supported: PDF, Word, Excel, Images, ZIP
5. Click **Submit**

**For Quiz Assignments:**
1. Questions appear one at a time or all at once
2. Select/type answers
3. Click **Submit Answer** for each question
4. Review before final submission
5. Cannot edit after submission

### Checking Submission Status

- **Not Submitted**: Complete and upload your work
- **Submitted**: Waiting for teacher to grade
- **Late**: Submitted after due date (may have penalties)
- **Graded**: View marks and feedback

### Viewing Grades

1. Click on graded assignment
2. See your grade and feedback
3. View rubric with scores
4. Teacher comments appear below
5. Resubmit if allowed by teacher

### Re-submission

If teacher allows:
1. Click **Resubmit**
2. Upload new file or text
3. Add resubmission note
4. Click **Submit**
5. Previous submission archived

### Assignment Troubleshooting

**Can't submit:**
- Check file size (max 25MB)
- Ensure file format is supported
- Clear browser cache
- Try different browser
- Check internet connection

**File didn't upload:**
- Verify file isn't corrupted
- Try uploading smaller file first
- Use different file format
- Contact teacher if issue persists

## 5. Assessments & Tests

### Taking a Test

**Before Starting:**
1. Find test in **Tests** section
2. Read instructions carefully
3. Check time limit
4. Note if test is timed per question
5. Ensure internet is stable

**During Test:**
1. Click **Start Test**
2. Answer all questions
3. Skip and return (if allowed)
4. Submit test to save progress
5. Cannot exit and re-enter once submitted

**Test Types:**
- Multiple Choice: Select correct option
- Short Answer: Type response
- Long Essay: Write paragraph(s)
- Matching: Match items to descriptions
- Fill in Blank: Complete statements
- Numerical: Enter numbers/formulas

### Test Navigation

- **Question Bank**: See all questions
- **Review**: Mark question for later review
- **Timer**: Shows remaining time
- **Submit**: Final submission when done

### Test Restrictions

Some tests have restrictions:
- **Time Limit**: Complete within specified time
- **Full Screen**: Cannot minimize window
- **No Copy/Paste**: Cannot copy text
- **One Attempt**: Cannot retake
- **IP Restriction**: Must be on campus network
- **Proctored**: Webcam monitoring

### Results & Score

After submission:
1. Automatic scoring (if applicable)
2. Manual review by teacher
3. Results available in **Grades**
4. See detailed breakdown if provided
5. Compare to class average (if available)

## 7. Attendance

### Checking Attendance

1. Click **Attendance** in menu
2. View attendance percentage
3. See all marked sessions
4. Filter by date range

### Attendance Breakdown

- **Present (P)**: Attended class
- **Absent (A)**: Not attended
- **Late (L)**: Marked late
- **Leave (LV)**: Authorized leave
- **Work from Home (WFH)**: Remote attendance

### Critical Attendance

- Minimum attendance usually 75%
- Below 75% shown in **At Risk**
- Contact teacher to request leave
- Apply for late excuse with reason
- Maintain records of leave applications

### Attendance Calculation

- Total classes conducted
- Total attended
- Percentage = (Attended / Total) × 100
- Exemptions (if any) applied

### Leave Management

**Requesting Leave:**
1. Go to **Leave Request**
2. Choose leave type
3. Select dates
4. Add reason
5. Upload documents (if medical)
6. Submit
7. Wait for approval

**Leave Status:**
- **Pending**: Awaiting approval
- **Approved**: Leave granted
- **Rejected**: Request denied with reason
- **Cancelled**: You cancelled the request

## 11. Troubleshooting

### Common Issues

**Can't Login**

*Symptom:* "Invalid credentials" error

Solutions:
1. Verify username/email is correct
2. Check caps lock on keyboard
3. Use "Forgot Password" to reset
4. Clear browser cache and cookies
5. Try different browser
6. Check if account is active (contact admin)

**Can't Access Course**

*Symptom:* "Not enrolled" or "Access denied"

Solutions:
1. Verify enrollment (check dashboard)
2. Wait 24 hours after enrollment
3. Clear browser cache
4. Check course prerequisites
5. Verify fees are paid (if required)
6. Contact admin

**Assignment Won't Upload**

*Symptom:* Upload button inactive or file rejected

Solutions:
1. Check file size (max 25MB)
2. Use supported file format
3. Scan for viruses
4. Check internet connection
5. Try different browser
6. Wait for deadline (may be closed)

**Can't See Grades**

*Symptom:* Grades section empty or says "No grades yet"

Solutions:
1. Assignment may not be graded yet
2. Grading may be hidden until class date
3. Check with teacher
4. Wait 24-48 hours after submission
5. Clear cache

**Video Won't Play**

*Symptom:* Black screen or error message

Solutions:
1. Check internet speed (requires 1Mbps minimum)
2. Clear browser cache
3. Disable browser extensions
4. Try different browser
5. Check if video format is supported
6. Update video player plugin
7. Try downloading video

**Payment Failed**

*Symptom:* Payment declined or stuck processing

Solutions:
1. Check card balance/limit
2. Verify card details
3. Try different payment method
4. Contact bank to verify
5. Use offline payment option
6. Contact admin for manual processing

### Browser Requirements

Recommended:
- Chrome (latest version)
- Firefox (latest version)
- Safari (latest version)
- Edge (latest version)

Supported Resolution: 1024×768 or higher

**Slow Performance:**
1. Close unnecessary tabs
2. Clear browser cache
3. Disable extensions
4. Check internet speed
5. Use wired connection
